Mechanism analysis in a textbook gives you one answer for one configuration. Change any parameter, and you start the calculation over. The 2D Mechanisms Analyzer gives you the full picture: adjust geometry in real time, see all seven kinematic curves update instantly, compare configurations side by side, and export professional-grade data for further analysis.

## Crank-Slider Mechanism Simulator

The crank-slider is the most widely used mechanism in engineering: internal combustion engines, reciprocating compressors, hydraulic presses, and packaging machinery all depend on it. Our simulator provides complete kinematic and force analysis for any configuration.

### Key Features

<Steps>
1. **Real-Time Animation**
   Watch the mechanism move at the RPM you set. Pause at any angle to inspect geometry. Show or hide the crank path, TDC/BDC markers, and dimensional labels.

2. **Seven Analysis Plots**
   Displacement, velocity, acceleration, mechanical advantage, connecting rod angle, transmission angle, and crank torque. All rendered on interactive charts with hover data readout.

3. **A/B Configuration Comparison**
   Save one configuration as Experiment A, change parameters, and run Experiment B. Both datasets overlay on every chart with distinct colors, making parametric studies visual and immediate.

4. **Negative and Positive Offset**
   Slider offset from -50 mm to +50 mm. Offset is what creates quick-return behavior in shapers and presses. Most textbooks only cover the inline case; this simulator shows the full picture.

5. **Professional Downloads**
   Export CSV data (361 data points across all 7 variables), PNG charts with watermark, design specifications with manufacturing tolerances, lab report templates, and parametric FreeCAD Python scripts.
</Steps>

### Equations

The simulator implements exact analytical solutions (not approximations):

**Position:**

```text
x = r * cos(theta) + sqrt(l^2 - (r * sin(theta) - e)^2)
```

**Velocity:**

```text
v = -r * omega * [sin(theta) + cos(theta) * (r * sin(theta) - e) / sqrt(l^2 - (r * sin(theta) - e)^2)]
```

**Acceleration:**

```text
Let S = r * sin(theta) - e,  Q = sqrt(l^2 - S^2)

a = omega^2 * [-r * cos(theta) + r * sin(theta) * S / Q - r^2 * cos^2(theta) * l^2 / Q^3]
```

Where r = crank length, l = connecting rod length, e = slider offset, theta = crank angle, and omega = angular velocity in rad/s.
